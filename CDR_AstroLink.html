1.2. Mission objectives

The AstroLink CanSat mission focuses on measuring air quality parameters at different atmospheric layers during descent. Our primary scientific objective is to create a vertical profile of particulate matter concentration from approximately 1 km altitude down to ground level.

Primary Mission

Measure atmospheric temperature and pressure during descent to calculate altitude and descent rate.

Secondary Mission

Investigate the vertical distribution of airborne particulate matter (PM1.0, PM2.5, PM4.0, PM10) using the Sensirion SPS30 sensor. This data will help understand how air pollution varies with altitude and can provide insights into:

  • Particulate matter concentration gradients in the lower atmosphere
  • The relationship between altitude and air quality
  • Potential sources of pollution at different atmospheric layers
  • Correlation between meteorological conditions (temperature, humidity) and particle distribution

Success Criteria

  • Successfully deploy from the launch vehicle and descend under parachute
  • Collect continuous sensor data throughout the flight
  • Transmit real-time telemetry to the ground station via LoRa
  • Store all flight data onboard for post-flight analysis
  • Safely land and be recovered intact
  • Remain operational for at least 4 hours after landing

2. CANSAT DESCRIPTION

2.1. Overview of the mission

The AstroLink CanSat will be launched on a rocket to an altitude of approximately 1 km, where it will be ejected and descend under a parachute system at a rate of 8-11 m/s. During descent, it will continuously measure atmospheric parameters using its sensor suite and transmit data to the ground station via LoRa radio link while simultaneously storing all data onboard. The satellite will remain active for at least 4 hours after landing to facilitate recovery.

Critical Components and Systems

  • Microcontroller: ESP32-S3 (dual-core, WiFi capable)
  • Primary sensors: BMP585 (pressure/temperature), GPS module (M100-Pro HGLRC)
  • Secondary mission sensor: SPS30 particulate matter sensor
  • Supporting sensors: BNO085 IMU, SCD40 (CO2/humidity), QMC5883L (magnetometer)
  • Communication: LoRa radio (SX1278 at 433.2 MHz / 868 MHz ISM band)
  • Power: Li-Ion 18650 battery with voltage regulation
  • Recovery: Parachute system

2.3. Electrical design

The electrical system is built around the ESP32-S3 microcontroller, providing sufficient processing power, memory, and connectivity for our mission requirements.

Microcontroller Specifications

  • MCU: ESP32-S3-DevKitC-1 N16R8
  • Processor: Dual-core Xtensa LX7 @ 240 MHz
  • RAM: 512 KB SRAM + 8 MB PSRAM
  • Flash: 16 MB (quad SPI)

Sensor Connections

Sensor Interface Pins Address/Speed
BNO085 (IMU) SPI GPIO5,6,7,15,10,11 SPI Mode
BMP585 (Pressure) I2C GPIO8 (SDA), GPIO9 (SCL) 0x47, 400 kHz
SCD40 (CO2) I2C GPIO8 (SDA), GPIO9 (SCL) 0x62, 400 kHz
QMC5883L (Magnetometer) I2C GPIO8 (SDA), GPIO9 (SCL) 0x0D, 400 kHz
M100-Pro HGLRC (GPS) UART1 GPIO17 (TX), GPIO18 (RX) 38400 baud
SPS30 (Particulate) UART2 GPIO14 (TX), GPIO13 (RX) 115200 baud
WS2812 (Status LED) GPIO GPIO48 -

LoRa Communication

Current design uses SX1278-based LoRa module at 433.2 MHz. System allows module replacement for 868 MHz ISM band compliance. The E22-900M30S (SX1262) is available as alternative.

2.4. Software design

The CanSat firmware is developed using ESP-IDF framework with FreeRTOS for real-time task management.

Development Environment

  • Framework: ESP-IDF (Espressif IoT Development Framework)
  • Build System: PlatformIO
  • Programming Language: C/C++
  • RTOS: FreeRTOS

Software Architecture

Multi-task architecture with dedicated task per sensor:

Task Priority Frequency Purpose
gps_task8~1 HzGPS UBX protocol parsing, position/velocity

bno085_task550 HzIMU quaternion, acceleration, gyroscope
bmp585_task610 HzPressure, temperature, altitude
scd40_task61 HzCO2, temperature, humidity

Data Storage

Battery Life Calculation

Battery: Cellevia CL-18650-29E/1S1P — Capacity: 2670 mAh, Energy: 9.75 Wh, Voltage: 3.7V

Power consumption analysis:

  • Peak power: ~1207 mW
  • Average power (LoRa TX ~10% duty): ~900 mW
  • Average current at 3.7V: ~243 mA

Estimated runtime:

  • Runtime = 2670 mAh / 243 mA = ~11 hours
  • With 80% efficiency margin: ~8.8 hours

Conclusion: Battery provides more than double the required 4-hour minimum, ensuring sufficient margin for mission and recovery.
